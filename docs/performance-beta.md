# 1.2.34-beta.1 性能测试说明

## 改动范围

- 连接级 SQL 编译缓存：最多 256 条、单条 SQL 最长 16,384 字符；不缓存结果或设置永久绑定参数。忙碌中的语句不复用，关闭数据库清空缓存。
- OCR 旧批处理队列在写事务外异步准备大字段，再核对页面归属后批量提交。并发删除的页面不复活，校对稿不覆盖。
- OCR 当前页和版本记录复用已准备的内容引用，避免同内容的重复序列化、哈希及文件检查。
- 正文读取缓存同时限制 256 条和 32MiB 的 UTF-16 字符存储预算；此预算不包含 Map 和路径等对象开销。超限条目不保留在缓存，但返回的正文不截断。切换数据根目录清缓存，缺失或损坏文件不做失败缓存。
- 不改全文检索查询条件、分词、匹配、分页或补扫策略，不删除正文、历史版本或索引。既有 v1/v2 正文引用继续可读。

## 本机观察

2026-09-09，Windows x64、Electron 39.8.10、better-sqlite3 12.10.0；隔离临时资料库，5,000 篇合成文献，各 1 页。测试不接触真实资料库，也不发送 AI/OCR 请求。

| 数据库阶段 | 修改前一次基线 | 修改后两次观察 |
| --- | ---: | ---: |
| 写入 5,000 条文献记录 | 554.3ms | 71.6–81.6ms |
| 写入 5,000 条完整页面记录 | 121.4ms | 26.1–29.7ms |
| 20,000 次正文定位查询 | 252.2ms | 57.9–63.6ms |
| 20,000 次队列式状态更新 | 423.0ms | 46.0–56.5ms |
| 已有测试库重开 | 15.1ms | 15.5–16.7ms |

另一次 32MiB 合成文件流式复制与完整 SHA-256 校验约 123ms。写入基准在事务中执行，是数据库微基准，不是文件导入端到端速度。数据库重开未见明确提速，不宣称启动速度提升。真实文件读取、解析、渲染与网络耗时需分开测量；远端 OCR/上传吞吐未实测。

## 回归命令

```powershell
npm run check:performance
npm run check:batch-processor-save
npm run check
npm run build
npm run check:research-graph-ui
npm run smoke
npm run smoke:packaged
```

`check:performance` 验证查询实时性、事务回滚、约束失败后的复用、表结构改变、连接隔离、忙语句、LRU 淘汰、旧正文引用恢复读取、超大正文完整性、5,000 文献重开与文件复制末尾内容校验。

`check:batch-processor-save` 验证真实 SQLite 批量保存，确认压缩不持有写事务、并发删除不复活、正文/布局无损、校对稿保留。

默认打包运行测试读取 `dist/win-unpacked`。测试包位于其他目录时设置 `GUJISMART_UNPACKED_DIR`。每次运行使用独立测试库；脚本输出实测时间，不采用依赖机器速度的硬性通过阈值。

## 测试分发

这是本地 beta，不推送仓库、不创建公开发行版。安装包只含应用与公开运行资源，不含测试库、用户文献或凭据。升级前通过应用备份；退出旧版本后安装到原安装目录，不要同时打开同一个资料库。安装到另一个位置不会自动读取旧目录的资料库。

通过迁移回归不等于验证所有历史用户环境。建议先用备份副本验证旧资料库、队列恢复、OCR 页面数、长正文末尾搜索、跨文献搜索和导出，再扩大试用范围。

## 本轮验证结果

- 全量 `npm run check`（包含生产构建）、`npm run smoke`、图谱窗口回归、打包离线冒烟与依赖审计通过。依赖审计为 0 个已知漏洞。
- 使用保留的 1.2.33 打包程序创建隔离库，再用 1.2.34-beta.1 打开同一库：两篇长文逐字一致，文末关键词均可检索，跨文献命中数保持 2。
- 上述升级试验中，到 preload API 可用的时间分别约 1491ms/1023ms；只有一次串行观察，缓存和系统负载不同，不能据此宣称稳定启动提速。常规 Electron 冒烟的项目选择页约 2260ms 可用。
- 阅读器已显示页面中的搜索导航，测试可见延迟 p95 约 19.1ms、最大约 25.8ms。不是首次全文检索耗时。
- NSIS 安装包已生成并完成载荷运行验证；未在用户真实安装目录执行安装/卸载，未调用远端付费 OCR。

旧版升级测试命令（两个路径必须由测试者显式提供）：

```powershell
$env:GUJISMART_OLD_EXECUTABLE = '<old unpacked executable>'
$env:GUJISMART_NEW_EXECUTABLE = '<new unpacked executable>'
node scripts/packaged-upgrade-regression.js
```

安装包构建使用 `electron-builder --win nsis --x64 --publish never --config.directories.output=dist/beta-1.2.34`，保留现有 `dist` 中的旧安装包用于对照，不自动删除旧产物。
