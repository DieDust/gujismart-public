# 全范围专题研究

本功能是 `large-corpus-research-plan.md` 的第一条可运行流程。它与原有快速问答并存，不替换已有研究数据，也不自动重建向量或调用模型。

## 使用

1. 在知识图谱的“向文献提问”页面选择文献、填写问题，点击“全范围专题研究”。
2. 确认当前范围和最多模型请求次数。默认 20 次，次数上限不是金额上限；完整处理长文献可能需要更多请求。
3. 准备正文快照后按块执行，显示成功、失败、待处理和累计发现数。可暂停后继续；关闭软件不会删除状态，重新打开后需主动继续。
4. 在文献研究表搜索、排序、分页和展开原文发现。综合概览保留相关材料链接，但属于待核验的模型综合，不是已确认的历史事实。
5. 失败只重试失败阶段；报告中间结果单独保存。要强制重新分析，可新建研究并取消“复用相同问题、正文和模型的成功结果”。

## 执行边界

- 不用检索命中或 8 条证据作为整个专题的范围上限。所有选中文献进入快照，所有可用正文分块进入任务；空页和缺文列为异常，不自动排除。
- 输入按 UTF-8 字节有界分块，保留 UTF-16 偏移和全部文字。正文块默认最多 12,000 字节，整个单次提示最多 24,000 字节；这些不是精确 Token 数。
- 每次请求输出最多 2048 Token。达到请求次数预算暂停；兼容重试与临时失败重试都计入次数。服务商未返回用量时，不伪造精确 Token 统计。
- 新旧批量研究共享串行模型通道；普通前台问答和 OCR 仍沿用各自控制，不声称全应用所有 AI 请求都被串行化。
- 可恢复的临时模型错误最多自动重试一次；连续错误停止后续调度。取消或暂停无法保证免除已发出请求的费用。
- 原文摘句必须逐字匹配当前正文；解析失败、引文不匹配、输出截断不能作为空发现成功。
- 模型明确返回输出截断时，自动缩小该正文块并串行重试，最多拆分三层；成功子块与拆分计划持久保存。所有子块成功前，不把原块标记为处理完成，相关请求仍受预算限制。
- 原文和模型相同、问题与提示完全相同时才复用提取。更换模型需切回原模型继续或创建新研究；不同资料库之间不共享提取缓存。
- 校对改变正文时不能把旧提取标为新版本完整处理。已有发现保留原始定位，读取时标记来源变化。页面增加或删除同样使本次快照失效。
- 报告完成前复核正文与范围，并在写事务内比较正文变更代数，防止校验到落库之间出现过期的完成状态；其他研究任务写入进度不影响该检查。
- 仅页码映射改变不重新调用模型；阅读和摘录使用现有稳定原文定位与引注处理。
- 原始材料不因创建或重跑研究而删除。新增持久数据使用既有任务、产物和研究证据表，并新增查询索引。

## 实体核对

新建全范围专题研究会在同一次正文抽取中提取人物、地点、机构、时间和事件名称，以及带原文说明的别名。无需单独向量化，也不会为每对名称再调用一次模型。每个名称必须实际出现在对应引句中，缺少实体字段的新输出会明确报错，不伪装成没有实体。

在研究结果中展开“实体核对”，可搜索名称、别名或文献，筛选同名候选，展开原文并跳回文献。选中记录后可“确认为同一对象”或“独立保留”，填写核对依据；最近操作可以撤销，依据与历史持久保留。归并作用于所选记录所属的整个对象组；分离只作用于所选记录。

- 自动归组只接受相同正文版本的同一处名称出现，及明确、无否定或争议的本地别名说明。不同文献的同名、同字号、相似语义不能独立证明身份，只提供候选。
- 同名候选按名称桶计算，不对所有名称进行两两模型比较。名称使用 NFC 规范化；不盲目简繁转换、去掉官职或消除时代差异。
- 核对不改动原文、引注和研究发现；正文已修改或缺失时阻止新的跨组归并。多窗口使用结果版本校验，过期操作必须刷新。
- 旧研究及其续跑保留原抽取约定；旧发现显示未提取实体，新建研究使用新版提示，缓存按提示隔离。不会自动重跑旧库、收取额外模型费用。
- 身份分组限于当前研究运行，不跨资料库传播。当前不会用核对结果悄悄改写旧版统计数据集图谱，也不把共现变成已证实的历史关系。

## 尚未承诺

本流程保证可检查的任务范围与恢复行为，不保证模型识别出每一条相关事实。分层综合仍可能遗漏小众观点，全部发现保留在研究表供核验；相关材料链接不等于经过独立语义审查的支持关系。

尚未完成专业标注集上的模型效果验收、真实千篇付费基准、金额上限估算、跨页表格语义重建及将专题发现自动转换为可靠图谱。自动实体整理和可撤销的人工消歧已接通，但不能保证模型命名或历史身份判断绝对正确。

当前任务历史入口显示最近 50 次运行，文献与发现分页读取；此历史显示限制不限制一次运行的文献范围。完整原文快照会占用额外本地存储，大资料库需预留空间。

## 验证

```powershell
npm run check:corpus-research
npm run build
npm run check:corpus-research-ui
npm run smoke
```

自动化测试使用临时数据库、虚构文献和模拟模型，不读取用户 API Key，不把真实资料上传。1000 篇测试验证范围、末篇证据、来源与调度机制，不代表真实模型已经通过千篇研究质量评审。

新增实体回归覆盖同名、别名、版本隔离、合并/分离/撤销、万条名称分组，以及持久化核对、跨库隔离、过期操作、正文修改、旧任务续跑与新版缓存隔离。专项集成测试包含 1001 篇范围用例，合计 30 个任务、1230 次模拟请求、零网络调用。界面测试覆盖 1024×900、1440×1000、3840×2032。
