## Task 2：typed settings 与 CredentialVault

- [x] 2.1 建立 `SettingDefinition` registry，声明 protected key、公开类型、默认值和 renderer 可见性。
- [x] 2.2 建立 main-only `CredentialVault`，用 `safeStorage` 和 versioned sidecar/journal 保存密文。

## Task 3：业务消费者与 UI

- [x] 3.1 AI、元数据重分类、OCR、视觉 OCR 和模型列表统一使用 main-only credential reader。
- [x] 3.2 `settings:get/getAll` 对 protected key 只返回 configured/last4/version 公共状态。
- [x] 3.3 设置页和首次引导不回填已保存 Key；空草稿表示保留原凭据，显式清除走专用命令。
- [x] 3.4 profile 列表、切换和事件只携带 public profile；切换后业务仍能读取对应 secret。
- [x] 3.5 普通备份 manifest 标记 `credentialsExcluded/credentialRequiredAfterRestore`，备份副本执行 protected-key 脱敏校验。
