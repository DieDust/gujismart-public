# 文献管理（GujiSmart）图文使用教程

本文面向第一次使用 **文献管理（GujiSmart）** 的研究者、学生和资料整理人员。你可以把它当作一条完整工作流：先配置 OCR 与 AI，再导入文献，随后完成整理、阅读、校对、检索、摘录、研究写作和导出。

![欢迎页](images/tutorial-01-welcome.png)

## 1. 认识软件

**文献管理（GujiSmart）** 是一个面向古籍、扫描件、PDF、图片和通用文本资料的本地研究工作台。它的核心思路是把“资料入库、OCR 识别、元数据整理、全文检索、阅读校对、摘录写作、引用导出”放在一个软件里完成。

软件左侧是主导航：

- **文献库**：导入、整理、筛选、批量处理文献。
- **研究**：建立研究专题，沉淀摘录、大纲、AI 分析和参考文献。
- **检索**：全文检索、AI 检索、导出命中摘录。
- **引用格式**：管理脚注、参考文献等引用模板。
- **标签**：维护全局标签。
- **处理队列**：查看 OCR 和批量任务进度。
- **设置**：配置 OCR、AI、备份、快捷键和术语表。

## 2. 启动软件

当前开源仓库提供的是源码版本。请先在项目根目录安装依赖并启动开发模式：

```bash
npm install
npm run dev
```

如果你需要自己构建生产包，可以运行：

```bash
npm run build
```

当前开源仓库只提交源码和必要资源，不提交本地构建产物；如需分发版本，请由维护者在本地构建后另行发布。

首次启动后会进入欢迎页。欢迎页提供常用入口：**导入文献**、**文献库**、**全文检索**、**引用格式** 和 **设置**。

## 3. 首次配置

第一次使用前，建议先打开左侧 **设置**。OCR、AI 和备份策略都在这里完成。

![设置页](images/tutorial-08-settings.png)

### 3.1 配置 OCR

进入 **设置** 后，找到 **PaddleOCR 接口**。

1. 在 **PaddleOCR API Token** 中填入飞桨 OCR 的 API Token。
2. 按需要选择 **PDF 异步 OCR 模型**。
3. 根据机器和网络情况调整上传超时、图片最长边和 JPEG 质量。
4. 点击页面底部 **保存设置**。

如果你处理的是古籍、报纸、复杂版面或扫描质量不稳定的资料，可以继续配置 **视觉模型 OCR**。视觉 OCR 支持 OpenAI-compatible 接口，可用于豆包/火山方舟、Qwen-VL、GLM-4V、OpenAI 等兼容视觉模型。

### 3.2 配置 AI

找到 **AI 模型接口**。

1. 选择模型提供方，例如 DeepSeek、Qwen、GLM、Moonshot、OpenAI、VolcEngine，或选择 **自定义**。
2. 填写 **API Base URL**。
3. 填写 **API Key**。
4. 填写默认模型。
5. 点击 **保存当前为服务商**，以后可在顶部快速切换。
6. 点击页面底部 **保存设置**。

AI 配置会影响这些功能：

- 文库 AI 问答。
- 文献内 AI 助手。
- AI 摘要、翻译、专题分析。
- AI 提取元数据。
- AI 辅助生成引用模板。

### 3.3 推荐开关

在 **批量处理** 区域，常用开关包括：

- **导入后自动 OCR**：导入 PDF 或图片后自动进入 OCR。
- **OCR 后自动 AI 分析**：默认关闭；用户开启后，识别完成会自动分类、写入元数据并生成标签。
- **OCR 完成后自动删除 PDF 原图**：只清理软件数据目录里的 PDF 副本和页图缓存，不会删除 PDF 原件仓库。
- **校对默认使用版式还原**：进入支持版式还原的文献时，优先打开版式还原校对。

全新安装默认开启 **导入后自动 OCR**、关闭 **OCR 后自动 AI 分析**。熟悉流程并完成 AI 服务配置后，再按需开启自动 AI 分析。

## 4. 导入文献

打开 **文献库**，可以通过欢迎页的 **导入文献**，也可以使用右下角的 **+** 浮动按钮导入。

![文献库](images/tutorial-02-library.png)

支持的常见格式包括：

- PDF。
- 图片：PNG、JPG、JPEG、TIFF、BMP。
- 文本：TXT、Markdown。
- EPUB。
- PaddleOCR JSON。

导入方式：

1. 点击右下角 **+**。
2. 选择一个或多个文件。
3. 也可以把文件或文件夹直接拖到导入按钮上。
4. 导入后，文献会出现在文献库列表中。
5. 如果开启了自动 OCR，软件会把任务送入处理队列。

导入后，文献卡片上会显示 OCR 状态、入库状态、阅读状态、标签、文件夹和元数据状态。常见状态包括 **待识别**、**识别中**、**已识别**、**处理失败**、**未读**、**在读**、**已读**、**待确认** 和 **已确认**。

## 5. 整理文献库

文献库是日常使用最频繁的页面。推荐按下面顺序整理：

1. 先用 **文件夹** 管大类，例如“论文”“古籍”“地方志”“报刊资料”。
2. 再用 **标签** 描述主题、朝代、人物、地点、文献类型。
3. 对重点文献点击星标，方便后续筛选。
4. 阅读时把状态改为 **未读**、**在读** 或 **已读**。
5. 对元数据不完整的文献，使用 **查看 / 编辑元数据** 或 **AI 提取元数据**。

文献卡片右侧的常用操作：

- **星标**：标记重点文献。
- **阅读状态**：切换未读、在读、已读。
- **标签**：快速给单篇文献加标签。
- **更多**：导出、AI 提取、重试处理、清理或恢复 PDF 原图等。
- **删除**：从库中移除文献。

批量整理时，可以进入批量选择模式，对多篇文献统一加入文件夹、添加标签、启动 AI 综合分析或批量处理。

## 6. 阅读与校对

在文献库中点击任意文献即可进入阅读器。阅读器通常包含两个主要模式：

- **阅读模式**：适合连续阅读、页内检索、目录跳转、翻译和 AI 摘要。
- **校对模式**：适合对照原图修正 OCR，支持文本列表校对和版式还原校对。

### 6.1 阅读模式

阅读模式中常用功能：

1. 使用 **目录** 打开章节导航。
2. 使用 **上一页 / 下一页** 或页码框跳转。
3. 在 **页内检索** 中搜索当前文献关键词。
4. 用 **显示设置** 调整主题、字号、行距、页面宽度。
5. 开启 **翻译模式** 查看并行翻译。
6. 点击右侧或浮动 **AI** 按钮，让 AI 基于当前文献或选中文本回答问题。

如果从检索结果进入文献，阅读器会自动跳转到命中页，并高亮关键词。

### 6.2 校对模式

校对模式适合 OCR 后检查文字：

1. 切换到 **校对模式**。
2. 左侧查看原图或页面鸟瞰。
3. 右侧修改 OCR 文本。
4. 如果本页识别效果不好，点击 **重新 OCR 本页**。
5. 如果配置了视觉 OCR，也可以从下拉菜单选择 **用视觉 OCR 重识别本页**。
6. 校对完成后，点击 **标记本页校对完成**。

如果文献有可用的版面坐标，校对页会提供 **版式还原**。它更适合古籍、报纸、竖排文本、复杂版面和扫描件。

### 6.3 导出单篇文献

在文献阅读页点击 **导出**，可选择：

- 阅读模式 PDF。
- 排版模式 PDF。
- 原图可搜索 PDF。
- Markdown。
- TEI-XML。
- TXT。
- PAGE XML。
- Paddle JSON。

如果你的目标是继续写作，优先导出 Markdown 或 TXT；如果目标是长期归档，优先保留 PDF、TEI-XML 或 PAGE XML。

## 7. 全文检索

进入左侧 **检索** 页面，输入关键词即可搜索标题、元数据和 OCR 全文。

![检索页](images/tutorial-04-search.png)

检索页支持两种模式：

- **全文检索**：直接按关键词匹配，速度快，适合确定词。
- **AI 检索**：由 AI 分析意图、扩展关键词和筛选条件，适合问题式检索。

常用步骤：

1. 在搜索框输入关键词，例如“地方志”“赋役”“学堂”“碑刻”。
2. 选择检索模式。
3. 根据需要设置文献、标签、文件夹、类型、年份、阅读状态等筛选条件。
4. 选择排序方式，例如相关度、命中数、最近更新、最近阅读、标题。
5. 点击结果卡片进入原文页。

检索结果会按文献分组，并展示命中页和片段。点击某个命中片段，会直接打开对应文献和页码。

### 7.1 保存和复用检索

常用主题可以点击 **保存检索**。下次进入检索页时，可以在 **保存的检索** 区域一键恢复。

### 7.2 导出命中摘录

点击 **导出命中摘录**，可以把命中关键词所在的完整自然段导出为：

- TXT。
- Markdown。
- CSV。
- JSON。

导出时可选择引用方式：

- **自动匹配引用格式**。
- **手动选择引用模板**。
- **简明引用**。

这适合做材料汇编、证据表、综述素材和读书笔记。

### 7.3 批量保存完整段落

点击 **批量保存完整段落**，可以把检索命中的完整段落保存为研究摘录，后续在 **研究** 页面统一整理到专题和大纲中。

## 8. 研究工作台

进入左侧 **研究**，可以把分散文献中的摘录组织成一个写作项目。

![研究工作台](images/tutorial-03-research.png)

推荐流程：

1. 点击 **新建专题**。
2. 填写专题名称，例如“明清地方志与区域社会”。
3. 在 **专题文献** 中加入相关文献。
4. 在 **专题与大纲** 中添加章节大纲。
5. 从阅读器、检索页或 AI 问答中保存摘录。
6. 把摘录归入对应大纲节点。
7. 使用 **写作预览** 查看 Markdown 草稿。
8. 使用 **带来源综述** 生成研究综述、主题分析、时间线、争议点或待读清单。

知识条目支持类型：

- **摘录**：原文材料。
- **概述**：对材料的概括。
- **评论**：你的判断和分析。
- **想法**：写作灵感或待验证问题。

研究页还可以导出或复制：

- 专题 Markdown。
- 专题 JSON。
- GB/T 7714 参考文献。
- BibTeX。
- RIS。

## 9. 文库 AI 助手

主界面右下角有 **AI** 浮动按钮。点击后会打开文库 AI 助手。

你可以让它：

- 基于整个文献库回答问题。
- 基于某个标签或文件夹回答问题。
- 对选中的多篇文献做综合分析。
- 总结研究脉络、争议点和材料空白。
- 根据检索结果继续追问。

在单篇文献阅读页中，右下角也有 **AI** 按钮。单篇文献 AI 更适合：

- 总结当前文献。
- 解释选中文本。
- 翻译段落。
- 提炼关键词。
- 帮你把材料改写为读书笔记。

## 10. 引用格式

进入左侧 **引用格式**，可以维护脚注和参考文献模板。

![引用格式](images/tutorial-05-citation.png)

引用格式页的结构是：

- **引用标准**：一整套引用规则，例如某期刊或某学科规范。
- **文献类型槽位**：专著、古籍、期刊、报纸、档案、电子文献等。
- **模板文本**：每种文献类型对应的格式。
- **示例预览**：用实际文献预览最终引用效果。

常用操作：

1. 点击 **新建引用标准** 创建一套规范。
2. 在每个文献类型旁点击 **设置此类型** 或 **编辑此类型**。
3. 填写模板文本和字段映射。
4. 如果已有一条正确示例，可以点击 **AI 识别**，让 AI 反推出模板草稿。
5. 保存后，在检索摘录导出或研究参考文献导出时选择这套标准。

如果暂时不想维护复杂模板，可以使用默认引用标准或简明引用。

## 11. 标签管理

进入左侧 **标签**，可以统一查看、创建、编辑和删除标签。

![标签管理](images/tutorial-06-tags.png)

标签可以来自：

- 手动创建。
- 导入时带入。
- AI 元数据分析生成。
- 文献字段同步生成。

推荐做法：

1. 用少量稳定标签表示核心主题。
2. 人名、地名、朝代、文献类型可以交给 AI 辅助生成。
3. 定期合并含义重复的标签。
4. 在标签页点击某个标签，可回到文献库查看对应文献。

## 12. 处理队列

进入左侧 **处理队列**，可以查看批量任务进度。

![处理队列](images/tutorial-07-dashboard.png)

这里会显示：

- 全部文献数量。
- 未入库数量。
- 已处理数量。
- 处理失败数量。
- 当前批次进度。
- 已处理、失败和总数。
- 预计剩余时间。

如果任务正在运行，可以执行：

- **暂停**：临时停止任务。
- **继续**：恢复任务。
- **取消**：终止当前任务。

处理失败的文献，可以回到文献库，在文献卡片上点击 **重试处理**。

## 13. 备份、迁移和数据目录

在 **设置** 页中可以管理备份。

建议：

1. 开启自动备份。
2. 默认使用轻量备份，保存数据库、OCR 文本、索引和元数据。
3. 需要迁移电脑时，使用 **导出完整备份**。
4. 在新电脑上使用 **导入备份并恢复**。
5. 需要排查文件时，点击 **打开数据目录** 或 **打开自动备份目录**。

如果你的 PDF 原件很多，可以添加 **PDF 原件仓库目录**。软件会只读登记能匹配文献库的 PDF 原件，需要原图校对时再复制回软件目录，不会修改、删除或移动仓库文件。

## 14. 翻译术语表

在 **设置** 页底部可以维护翻译术语表。

术语表分为：

- **全局术语**：所有翻译默认使用。
- **项目术语**：只在某个研究专题中使用，并可覆盖同名全局术语。

适合加入术语表的内容：

- 专有名词。
- 人名、地名、机构名。
- 学科术语。
- 古籍、报刊或档案中的固定译名。

维护术语后，阅读器的翻译模式会优先参考这些译名，减少同一术语在不同页面出现不同译法。

## 15. 推荐工作流

### 15.1 处理扫描古籍

1. 在 **设置** 中配置 PaddleOCR 和视觉 OCR。
2. 在 **文献库** 导入 PDF 或图片。
3. 等待 **处理队列** 完成 OCR。
4. 打开文献，进入 **校对模式**。
5. 对重要页面使用 **重新 OCR 本页** 或视觉 OCR。
6. 校对完成后标记页面。
7. 使用 **AI 提取元数据** 整理题名、责任者、版本、出版信息。
8. 导出 TEI-XML、PAGE XML、Markdown 或可搜索 PDF。

### 15.2 写一篇文献综述

1. 导入论文、图书和相关资料。
2. 用 **标签** 和 **文件夹** 整理主题。
3. 在 **检索** 中搜索核心概念。
4. 将命中段落批量保存为摘录。
5. 在 **研究** 中新建专题和大纲。
6. 把摘录归入大纲节点。
7. 使用 **带来源综述** 生成初稿材料。
8. 复制 Markdown 到写作软件继续修改。
9. 在 **引用格式** 中选择引用标准，导出参考文献。

### 15.3 做材料摘编

1. 导入资料。
2. OCR 完成后进入 **检索**。
3. 搜索人物、地名、制度名或关键词。
4. 点击 **导出命中摘录**。
5. 选择 Markdown、CSV 或 JSON。
6. 选择自动匹配引用格式。
7. 导出后按主题整理。

## 16. 常见问题

### OCR 没有开始

先检查 **设置** 中是否填写了 PaddleOCR API Token，并确认 **导入后自动 OCR** 是否开启。也可以在文献页或文献库中手动重试处理。

### AI 功能不可用

检查 **AI 模型接口** 的 API Base URL、API Key 和模型 ID 是否正确。保存后可以把当前配置保存为服务商，方便后续切换。

### 检索不到刚导入的文献

新导入文献需要先完成 OCR 或文本索引。等待处理队列完成后再检索。TXT、Markdown 和 EPUB 通常会更快进入可检索状态。

### 扫描件文字错得多

可以在阅读器中进入 **校对模式**，对当前页使用 **重新 OCR 本页**。复杂版面建议尝试视觉 OCR，并使用版式还原校对。

### 导出摘录没有引用

先检查文献元数据是否完整，尤其是题名、作者、年份、来源和文献类型。必要时在文献库中点击 **AI 提取元数据** 或手动编辑元数据。

### 数据迁移到新电脑

在旧电脑 **设置** 中点击 **导出完整备份**。在新电脑安装软件后，进入 **设置**，点击 **导入备份并恢复**。

## 17. 快速速查

| 目标 | 去哪里 | 使用什么功能 |
| --- | --- | --- |
| 导入 PDF 或图片 | 文献库 / 欢迎页 | 导入文献、拖拽导入 |
| 批量 OCR | 设置 + 处理队列 | 导入后自动 OCR、批量处理 |
| 修正 OCR | 阅读器 | 校对模式、重新 OCR 本页 |
| 找资料 | 检索 | 全文检索、AI 检索、筛选 |
| 保存证据 | 检索 / 阅读器 | 保存摘录、批量保存完整段落 |
| 写综述 | 研究 | 专题、大纲、带来源综述 |
| 管引用 | 引用格式 | 引用标准、模板、AI 识别 |
| 管主题 | 标签 / 文献库 | 标签、文件夹、星标、阅读状态 |
| 迁移数据 | 设置 | 导出完整备份、导入备份并恢复 |

完成这些配置后，最常用的日常路径就是：

```text
导入文献 -> OCR -> 元数据整理 -> 检索 -> 阅读校对 -> 摘录 -> 研究专题 -> 引用/导出
```
