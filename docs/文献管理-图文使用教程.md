# 文献管理（GujiSmart）图文使用教程

本文面向第一次使用 **文献管理（GujiSmart）** 的研究者、学生和资料整理人员。你可以把它当作一条完整工作流：先配置 OCR、AI 与向量索引，再导入文献，随后完成整理、识别校对、全文/向量检索、摘录、研究写作和导出。

> 说明：正文已按 **1.1.10** 能力增补；配图若与界面略有出入，以当前软件为准。截图请尽量使用空库或合成示例数据。

![欢迎页](images/tutorial-01-welcome.png)

## 1. 认识软件

**文献管理（GujiSmart）** 是一个面向古籍、扫描件、PDF、图片和通用文本资料的本地研究工作台。它的核心思路是把“资料入库、OCR 识别、元数据整理、全文检索与向量检索、阅读校对、摘录写作、引用导出、AI 工具连接”放在一个软件里完成。

软件左侧是主导航：

- **文献库**：导入、整理、筛选、批量 OCR、批量向量化、补回/清理原文等。
- **文件夹**：以树形结构管理文件夹，并对文件夹内文献做批量操作。
- **研究**：建立研究专题，沉淀摘录、大纲、AI 分析和参考文献。
- **检索**：**全文检索** 与 **向量库检索**（语义检索）；导出命中摘录。
- **引用格式**：管理脚注、参考文献等引用模板。
- **标签**：维护全局标签。
- **处理队列**：查看 OCR、向量化和各类批量任务进度。
- **设置**：配置 OCR、AI、向量索引、PDF 原件仓库、备份、快捷键、术语表和 MCP 等。

## 2. 启动软件

### 2.1 普通用户（推荐）

请到 GitHub [Releases](https://github.com/DieDust/gujismart-public/releases) 下载最新安装包：

- `GujiSmart-*-Setup-x64.exe`：安装版，适合长期使用。
- `GujiSmart-*-Portable-x64.exe`：便携版，适合免安装运行。

安装或解压后直接启动即可。数据默认保存在可执行文件附近的 `data/` 目录（可在 **设置 → 数据管理** 中打开确认）。

### 2.2 源码开发

当前开源仓库也提供源码。请先在项目根目录安装依赖并启动开发模式：

```bash
npm install
npm run dev
```

如果你需要自己构建生产包，可以运行：

```bash
npm run build
```

当前开源仓库只提交源码和必要资源，不提交本地构建产物；正式分发版本请使用 Releases 中的安装包，或由维护者按发布规范构建。

首次启动后会进入欢迎页。欢迎页提供常用入口：**导入文献**、**文献库**、**全文检索**、**引用格式** 和 **设置**。

## 3. 首次配置

第一次使用前，建议先打开左侧 **设置**。OCR、AI 和备份策略都在这里完成。

![设置页](images/tutorial-08-settings.png)

### 3.1 配置 OCR

进入 **设置** 后，找到 **PaddleOCR 接口**。

1. 在 **添加 API Token** 中填入飞桨 OCR 的 API Token，点击 **添加**。可以连续添加多个账号的 Token。
2. Token 会加密保存在本机。可以在轮询池中停用或删除某个 Token；界面只显示末四位，不会回显完整密钥。
3. 软件会连续使用当前 Token。飞桨返回 429（当日额度用完）或 403（Token 无效）后，会自动切换到下一个已启用 Token。
4. 按需要选择 **PDF 异步 OCR 模型**。
5. 根据机器和网络情况调整上传超时、图片最长边和 JPEG 质量。
6. 点击页面底部 **保存设置**。

飞桨官方接口单个任务最多处理 100 页，因此长 PDF 会按最多 100 页分段。每个成功分段会立即保存；某个 Token 中途用完额度时，只会用下一个 Token 重试失败分段，不会重新 OCR 已完成页面。官方没有提供可直接查询剩余额度的接口，软件以 429/403 响应作为切换依据。详见 [飞桨 API 配额规则和错误码说明](https://ai.baidu.com/ai-doc/AISTUDIO/Xmjclapam)。

如果你处理的是古籍、报纸、复杂版面或扫描质量不稳定的资料，可以继续配置 **视觉模型 OCR**（有的界面也叫 AI OCR / 大模型 OCR）。视觉 OCR 支持 OpenAI-compatible 接口，可用于豆包/火山方舟、Qwen-VL、GLM-4V、OpenAI 等兼容视觉模型。

配置视觉 OCR 时请注意：

1. 填写 **API Base URL**、**API Key** 和 **模型 ID**（豆包/火山请使用控制台里的完整接入点或模型 ID）。
2. 点击 **测试连接**。测试成功后再保存；若提示图片尺寸过小，请升级到 1.1.10 或更高版本后再测。
3. 在文献库批量处理或单页重识别时，可以选择视觉 OCR 或混合策略（以当前界面选项为准）。

另外，**批量处理 / OCR** 区域里还可以设置 **单本 OCR 超时**（墙钟时间）。某本书卡住过久时，会跳过该本并继续处理队列中的其他文献，避免一整批任务被一本“卡死”。

### 3.2 配置 AI

找到 **AI 模型接口**（或 AI 配置中心）。

1. 选择模型提供方，例如 DeepSeek、Qwen、GLM、Moonshot、OpenAI、VolcEngine，或选择 **自定义**。
2. 填写 **API Base URL**。
3. 填写 **API Key**。
4. 填写默认模型。
5. 点击 **保存当前为服务商**，以后可在顶部快速切换。
6. 点击页面底部 **保存设置**。

AI 配置会影响这些功能：

- 文库 AI 问答。
- 文献内 AI 助手。
- AI 摘要、翻译、专题分析。
- AI 提取元数据。
- AI 辅助生成引用模板。

### 3.3 配置向量索引

如果你需要按“意思”检索，而不是只搜固定关键词，请继续配置 **向量索引**（设置页中的「向量索引」分组）：

1. 选择与 AI 配置兼容的 Embeddings 服务商（例如通义、OpenAI 兼容接口等）。
2. 填写或复用 Base URL 与 API Key，再选择向量模型（如 `text-embedding-v3`）。
3. 保存设置。

当前版本主要对 **OCR/校对后的正文** 建立向量。配置完成后，可以在文献库做 **批量向量化**，并在检索页使用 **向量库检索**。

### 3.4 配置 PDF 原件仓库

如果你的 PDF 原件很多，建议在 **设置 → PDF 原件仓库** 中添加 NAS、移动硬盘或资料库目录，并点击 **立即扫描**。软件会只读扫描并匹配已导入文献的 PDF 原件。

这里有一个和“省空间 / 补回速度”相关的开关：

- **补回原文时仅登记路径（不复制）**（默认关闭）  
  - 关闭：补回时把 PDF **复制进软件数据目录**，最稳妥，大书会慢一些。  
  - 开启：只把外部路径登记到文献，**不整本复制**，大书补回会快很多；但外盘拔掉或文件移动后需要重新补回。

无论是否开启上述开关，**清理 OCR 原图** 都只删除软件数据目录（`storage`）里的副本和页图缓存，**绝不会删除** PDF 原件仓库、NAS 或“仅登记路径”指向的外部源文件。

### 3.5 配置 AI 工具连接（MCP）

如果你使用 Cursor、Claude Desktop、Codex、Trae 等 AI 客户端，希望它们直接只读检索你的文献库，可以打开 **设置 → AI 工具连接**，按说明一键写入配置。详见同目录文档 [MCP.md](MCP.md)。

### 3.6 推荐开关

在 **批量处理 / 自动化** 区域，常用开关包括：

- **导入后自动 OCR**：导入 PDF 或图片后自动进入 OCR。
- **OCR 后自动 AI 分析**：默认关闭；用户开启后，识别完成会自动分类、写入元数据并生成标签。
- **OCR 完成后自动删除 PDF 原图**：只清理软件数据目录里的 PDF 副本和页图缓存，不会删除 PDF 原件仓库，也不会删除外部链接的源文件。
- **校对默认使用版式还原**：进入支持版式还原的文献时，优先打开版式还原校对。
- **默认使用阅读模式**：打开文献时优先进入阅读模式；你在某本书上手动切换过模式后，仍以该书的选择为准。

全新安装默认开启 **导入后自动 OCR**、关闭 **OCR 后自动 AI 分析**。熟悉流程并完成 AI 服务配置后，再按需开启自动 AI 分析。

## 4. 导入文献

打开 **文献库**，可以通过欢迎页的 **导入文献**，也可以使用右下角的 **+** 浮动按钮导入。

![文献库](images/tutorial-02-library.png)

支持的常见格式包括：

- PDF。
- 图片：PNG、JPG、JPEG、TIFF、BMP。
- 文本：TXT、Markdown。
- EPUB。
- PaddleOCR JSON。

导入方式：

1. 点击右下角 **+**。
2. 选择一个或多个文件。
3. 也可以把文件或文件夹直接拖到导入按钮上。
4. 导入后，文献会出现在文献库列表中。
5. 如果开启了自动 OCR，软件会把任务送入处理队列。

导入后，文献卡片上会显示 OCR 状态、入库状态、阅读状态、标签、文件夹、原文状态和元数据状态。常见状态包括 **待识别**、**识别中**、**已识别**、**处理失败**、**未读**、**在读**、**已读**、**待确认**、**已确认**，以及原文相关的 **有原文**、**仅文本**、**链接原文** 等。

如果某本书 OCR 总体完成但个别页面失败，卡片上可能出现黄色提示，例如“OCR完成，第 3、7-9 页 OCR 未成功”。这不代表整本书失败，正文仍可检索和阅读；失败页可以稍后在校对模式中单独重试。

## 5. 整理文献库

文献库是日常使用最频繁的页面。推荐按下面顺序整理：

1. 先用 **文件夹** 管大类，例如“论文”“古籍”“地方志”“报刊资料”。也可以进入左侧 **文件夹** 页做更完整的树形管理。
2. 再用 **标签** 描述主题、朝代、人物、地点、文献类型。
3. 对重点文献点击星标，方便后续筛选。
4. 阅读时把状态改为 **未读**、**在读** 或 **已读**。
5. 对元数据不完整的文献，使用 **查看 / 编辑元数据** 或 **AI 提取元数据**。
6. 需要语义检索时，对已 OCR 文献执行 **批量向量化**（见 5.2）。

侧边或顶部的智能筛选（名称可能随版本略有差异）常用于快速找到：

- 尚未 OCR 或 OCR 未完成的文献。
- 已 OCR 但尚未向量化的文献。
- 向量排队中、向量化中或向量失败的文献。

这些筛选可以和文件夹、标签组合使用。

文献卡片右侧的常用操作：

- **星标**：标记重点文献。
- **阅读状态**：切换未读、在读、已读。
- **标签**：快速给单篇文献加标签。
- **更多**：导出、AI 提取、重试处理、清理或补回 PDF 原图、向量相关操作等。
- **删除**：从库中移除文献。

批量整理时，可以进入批量选择模式，对多篇文献统一加入文件夹、添加标签、启动 AI 综合分析或批量处理。

### 5.1 批量 OCR

在文献库批量菜单中，常见选项包括：

- **批量 OCR · 飞桨**
- **批量 OCR · 大模型**（需已配置视觉 OCR）
- **重新 OCR**（会覆盖整本识别结果，请谨慎使用）

批量 OCR 时请记住：

1. 同时处理多少本，由设置里的 **批大小**（并发）决定，不是“一次只跑固定 8 本”的硬编码。
2. 若开启了 **单本 OCR 超时**，某一本卡太久会跳过并继续后面的书。
3. **部分页面失败不会把整本书标成彻底失败**。书仍可入库；失败页会写进复核提示，可在校对页鸟瞰中定位。
4. 取消 OCR 后，已完成的页面会保留；该本不会被旧队列莫名其妙地自动续跑。

### 5.2 批量向量化

在已配置向量索引的前提下：

1. 选中若干文献。
2. 选择 **批量向量化 · 先 OCR(飞桨) 再向量**。
3. 软件会先判断哪些书还没有可用 OCR 正文：  
   - **还没有 OCR 正文** 的书：先用飞桨 OCR，完成后再入向量队。  
   - **已经 OCR 完成** 的书：**不会重新整本 OCR**，直接进入向量化。  
4. 已经向量化完成、或正在排队/处理中的书，普通“向量化”会跳过；若要换模型重建，请用 **重新向量化 · 覆盖重建**。
5. 进度会出现在文献卡片和处理队列中；可以停止排队或停止全部向量化。

如果你只是想给“已经识别好的书”建检索索引，优先用批量向量化，而不要再点一遍整库重新 OCR。

## 6. 阅读与校对

在文献库中点击任意文献即可进入阅读器。阅读器通常包含两个主要模式：

- **阅读模式**：适合连续阅读、页内检索、目录跳转、翻译和 AI 摘要。
- **校对模式**：适合对照原图修正 OCR，支持文本列表校对和版式还原校对。

### 6.1 阅读模式

阅读模式中常用功能：

1. 使用 **目录** 打开章节导航。
2. 使用 **上一页 / 下一页** 或页码框跳转。
3. 在 **页内检索** 中搜索当前文献关键词。
4. 用 **显示设置** 调整主题、字号、行距、页面宽度。
5. 开启 **翻译模式** 查看并行翻译。
6. 点击右侧或浮动 **AI** 按钮，让 AI 基于当前文献或选中文本回答问题。
7. 关注页码显示：**自然页码** 是 PDF/扫描的物理页序；**文献页码** 是书上的印刷页。可以点击文献页码进行校准，本页起向后按 +1 顺延；也可以重置为自动识别。

如果从全文检索或向量检索进入文献，阅读器会尽量跳转到命中页。全文检索会高亮关键词；向量检索会在侧栏显示向量命中与相似度，并可在「文本 / 向量」导航模式间切换。

### 6.2 校对模式

校对模式适合 OCR 后检查文字：

1. 切换到 **校对模式**。如果当前文献是“仅文本”、缺少可用 PDF，软件会尝试从原件仓库补回；补回失败时可手动选择 PDF。
2. 左侧查看 **原图**、**单页** 或 **鸟瞰**。
3. 如果有 OCR 失败页，可以在鸟瞰中筛选 **OCR失败**，或点击顶部失败页提示跳转到鸟瞰，逐页定位。
4. 右侧修改 OCR 文本；也可以删除错误文本块（版式还原与普通文本校对均支持）。
5. 如果本页识别效果不好，点击 **重新 OCR 本页**。
6. 如果配置了视觉 OCR，也可以从下拉菜单选择 **用视觉 OCR 重识别本页**。
7. 校对完成后，点击 **标记本页校对完成**。

如果文献有可用的版面坐标，校对页会提供 **版式还原**。它更适合古籍、报纸、竖排文本、复杂版面和扫描件。版式还原中也可以划选或点块复制原文、复制直接引用（默认快捷键可在设置中查看，常见为 `Ctrl+D`）。

### 6.3 导出单篇文献

在文献阅读页点击 **导出**，可选择：

- 阅读模式 PDF。
- 排版模式 PDF。
- 原图可搜索 PDF。
- Markdown。
- TEI-XML。
- TXT。
- PAGE XML。
- Paddle JSON。

导出时还可以选择页码模式：

- **文献页码**：优先使用印刷页（适合引用）。
- **自然页码**：使用物理页序 1、2、3…。

如果你的目标是继续写作，优先导出 Markdown 或 TXT；如果目标是长期归档，优先保留 PDF、TEI-XML 或 PAGE XML。

## 7. 检索

进入左侧 **检索** 页面。

![检索页](images/tutorial-04-search.png)

检索页现在至少包含两类能力：

- **全文检索**：直接按关键词匹配标题、元数据和 OCR 正文，速度快，适合确定词。
- **向量库检索**：按语义相似度检索正文片段，适合“意思接近、措辞不同”的问题。使用前请先完成 **设置 → 向量索引**，并对目标文献完成向量化。
- 部分版本仍可能提供 **AI 检索**（由 AI 扩展关键词与筛选），以当前界面选项为准。

### 7.1 全文检索常用步骤

1. 在搜索框输入关键词，例如“地方志”“赋役”“学堂”“碑刻”。
2. 选择 **全文检索** 模式。
3. 根据需要设置文献、标签、文件夹、类型、年份、阅读状态等筛选条件。
4. 选择排序方式，例如相关度、命中数、最近更新、最近阅读、标题。
5. 点击结果卡片或命中片段，进入对应文献和页码。

检索结果会按文献分组，并展示命中页和片段。

### 7.2 向量库检索常用步骤

1. 确认相关文献已经 OCR，并完成批量向量化。
2. 在检索页切换到 **向量库检索**。
3. 用自然语言描述你要找的内容，例如“关于赋役改革的地方实践”。
4. 查看命中片段与相似度；打开文献后，可在阅读器侧栏继续按向量命中跳转。
5. 如需导出向量证据，导出结果中会保留相似度等字段（不会误走成普通全文导出逻辑）。

### 7.3 保存和复用检索

常用主题可以点击 **保存检索**。下次进入检索页时，可以在 **保存的检索** 区域一键恢复。

### 7.4 导出命中摘录

点击 **导出命中摘录**，可以把命中关键词所在的完整自然段导出为：

- TXT。
- Markdown。
- CSV。
- JSON。

导出时可选择引用方式：

- **自动匹配引用格式**。
- **手动选择引用模板**。
- **简明引用**。

这适合做材料汇编、证据表、综述素材和读书笔记。

### 7.5 批量保存完整段落

点击 **批量保存完整段落**，可以把检索命中的完整段落保存为研究摘录，后续在 **研究** 页面统一整理到专题和大纲中。

## 8. 研究工作台

进入左侧 **研究**，可以把分散文献中的摘录组织成一个写作项目。

![研究工作台](images/tutorial-03-research.png)

推荐流程：

1. 点击 **新建专题**。
2. 填写专题名称，例如“明清地方志与区域社会”。
3. 在 **专题文献** 中加入相关文献。
4. 在 **专题与大纲** 中添加章节大纲。
5. 从阅读器、检索页或 AI 问答中保存摘录。
6. 把摘录归入对应大纲节点。
7. 使用 **写作预览** 查看 Markdown 草稿。
8. 使用 **带来源综述** 生成研究综述、主题分析、时间线、争议点或待读清单。

知识条目支持类型：

- **摘录**：原文材料。
- **概述**：对材料的概括。
- **评论**：你的判断和分析。
- **想法**：写作灵感或待验证问题。

研究页还可以导出或复制：

- 专题 Markdown。
- 专题 JSON。
- GB/T 7714 参考文献。
- BibTeX。
- RIS。

## 9. 文库 AI 助手

主界面右下角有 **AI** 浮动按钮。点击后会打开文库 AI 助手。

你可以让它：

- 基于整个文献库回答问题。
- 基于某个标签或文件夹回答问题。
- 对选中的多篇文献做综合分析。
- 总结研究脉络、争议点和材料空白。
- 根据检索结果继续追问。

在单篇文献阅读页中，右下角也有 **AI** 按钮。单篇文献 AI 更适合：

- 总结当前文献。
- 解释选中文本。
- 翻译段落。
- 提炼关键词。
- 帮你把材料改写为读书笔记。

如果你希望 Cursor、Claude、Codex、Trae 等外部 AI 客户端也能只读访问文献库，请到 **设置 → AI 工具连接（MCP）** 按说明配置。详见 [MCP.md](MCP.md)。

## 10. 引用格式

进入左侧 **引用格式**，可以维护脚注和参考文献模板。

![引用格式](images/tutorial-05-citation.png)

引用格式页的结构是：

- **引用标准**：一整套引用规则，例如某期刊或某学科规范。
- **文献类型槽位**：专著、古籍、期刊、报纸、档案、电子文献等。
- **模板文本**：每种文献类型对应的格式。
- **示例预览**：用实际文献预览最终引用效果。

常用操作：

1. 点击 **新建引用标准** 创建一套规范。
2. 在每个文献类型旁点击 **设置此类型** 或 **编辑此类型**。
3. 填写模板文本和字段映射。
4. 如果已有一条正确示例，可以点击 **AI 识别**，让 AI 反推出模板草稿。
5. 保存后，在检索摘录导出或研究参考文献导出时选择这套标准。

如果暂时不想维护复杂模板，可以使用默认引用标准或简明引用。

## 11. 标签管理

进入左侧 **标签**，可以统一查看、创建、编辑和删除标签。

![标签管理](images/tutorial-06-tags.png)

标签可以来自：

- 手动创建。
- 导入时带入。
- AI 元数据分析生成。
- 文献字段同步生成。

推荐做法：

1. 用少量稳定标签表示核心主题。
2. 人名、地名、朝代、文献类型可以交给 AI 辅助生成。
3. 定期合并含义重复的标签。
4. 在标签页点击某个标签，可回到文献库查看对应文献。

## 12. 处理队列

进入左侧 **处理队列**，可以查看批量任务进度。

![处理队列](images/tutorial-07-dashboard.png)

这里会显示：

- 全部文献数量。
- 未入库数量。
- 已处理数量。
- 处理失败数量。
- 当前批次进度。
- 已处理、失败和总数。
- 预计剩余时间。
- OCR、向量化等后台任务的排队与进度（以当前界面为准）。

如果任务正在运行，可以执行：

- **暂停**：临时停止任务。
- **继续**：恢复任务。
- **取消**：终止当前任务。

处理失败的文献，可以回到文献库，在文献卡片上点击 **重试处理**。向量化失败时，可在设置或文献库中按提示重试向量任务。

## 13. 备份、迁移和数据目录

在 **设置** 页中可以管理备份。

建议：

1. 开启自动备份。
2. 默认使用轻量备份，保存数据库、OCR 文本、索引和元数据。
3. 需要迁移电脑时，使用 **导出完整备份**。
4. 在新电脑上使用 **导入备份并恢复**。
5. 需要排查文件时，点击 **打开数据目录** 或 **打开自动备份目录**。

### 13.1 PDF 原件仓库、补回与清理

如果你的 PDF 原件很多，可以添加 **PDF 原件仓库目录**。软件会只读扫描并匹配已导入文献的 PDF 原件。

需要原图校对时：

1. 在文献卡片或校对页使用 **补回原文 / 补回 PDF**。
2. 默认会把 PDF **复制**进软件数据目录，最稳妥。
3. 若在设置中开启了 **补回原文时仅登记路径（不复制）**，则只登记外部路径，不整本复制，速度更快，但依赖原路径一直可用。
4. 也可以 **手动选择 PDF** 补回。

清理时请放心：

- **清理 OCR 原图 / 删除所选原文件** 只会删除软件数据目录 `storage/{文献ID}/` 内的副本和页图。
- **不会删除** PDF 原件仓库、NAS、移动硬盘上的源文件，也不会删除“仅登记路径”指向的外部 PDF。
- 清理后文献可能显示为 **仅文本**；正文与 OCR 结果仍在，需要原图时再补回即可。

## 14. 翻译术语表

在 **设置** 页底部可以维护翻译术语表。

术语表分为：

- **全局术语**：所有翻译默认使用。
- **项目术语**：只在某个研究专题中使用，并可覆盖同名全局术语。

适合加入术语表的内容：

- 专有名词。
- 人名、地名、机构名。
- 学科术语。
- 古籍、报刊或档案中的固定译名。

维护术语后，阅读器的翻译模式会优先参考这些译名，减少同一术语在不同页面出现不同译法。

## 15. 推荐工作流

### 15.1 处理扫描古籍

1. 在 **设置** 中配置 PaddleOCR 和视觉 OCR。
2. 在 **文献库** 导入 PDF 或图片。
3. 等待 **处理队列** 完成 OCR。
4. 打开文献，进入 **校对模式**。
5. 对重要页面使用 **重新 OCR 本页** 或视觉 OCR。
6. 校对完成后标记页面。
7. 使用 **AI 提取元数据** 整理题名、责任者、版本、出版信息。
8. 导出 TEI-XML、PAGE XML、Markdown 或可搜索 PDF。

### 15.2 写一篇文献综述

1. 导入论文、图书和相关资料。
2. 用 **标签** 和 **文件夹** 整理主题。
3. 在 **检索** 中搜索核心概念。
4. 将命中段落批量保存为摘录。
5. 在 **研究** 中新建专题和大纲。
6. 把摘录归入大纲节点。
7. 使用 **带来源综述** 生成初稿材料。
8. 复制 Markdown 到写作软件继续修改。
9. 在 **引用格式** 中选择引用标准，导出参考文献。

### 15.3 做材料摘编

1. 导入资料。
2. OCR 完成后进入 **检索**。
3. 搜索人物、地名、制度名或关键词。
4. 点击 **导出命中摘录**。
5. 选择 Markdown、CSV 或 JSON。
6. 选择自动匹配引用格式。
7. 导出后按主题整理。

## 16. 常见问题

### OCR 没有开始

先检查 **设置** 中是否至少启用了一个 PaddleOCR API Token，并确认 **导入后自动 OCR** 是否开启。如果 Token 显示“今日额度已用完”或“Token 无效”，请添加另一个 Token；也可以在文献页或文献库中手动重试处理。

### 某几页 OCR 失败了，整本书是不是废了？

不是。1.1.10 起，**单页失败不会拖垮整本**：文献仍可按识别完成入库。卡片上会用简短黄条标出失败页码。请打开该书 → **校对模式 → 鸟瞰**，筛选 OCR 失败页后，对单页重新 OCR 或使用视觉 OCR。

### 批量向量化时，已经 OCR 过的书又开始 OCR 了？

请确认使用的是 1.1.10 或更高版本。当前逻辑是：只有**还没有可用 OCR 正文**的书才会自动先 OCR；已经 OCR 完成的书会直接入向量队。若仍出现整本重跑，请检查该书 OCR 状态是否其实未完成，或是否误点了“重新 OCR”。

### 补回原文很慢

默认补回会把 PDF **整本复制**进软件目录，大扫描件会花较长时间。可以在 **设置 → PDF 原件仓库** 开启 **补回原文时仅登记路径（不复制）** 再补回。注意：链接模式下外盘不能随便拔。清理原图不会删外部源文件。

### 清理 OCR 原图会不会删掉我硬盘/仓库里的 PDF？

不会。清理只针对软件数据目录里的副本和页图；PDF 原件仓库和外部源文件只读、不删。

### 豆包视觉 OCR「测试连接」报图片太小

1.1.10 起连接测试图已改为合规尺寸。请升级后重试。若仍失败，再检查 Base URL、模型 ID 和 API Key。

### AI 功能不可用

检查 **AI 模型接口** 的 API Base URL、API Key 和模型 ID 是否正确。保存后可以把当前配置保存为服务商，方便后续切换。

### 检索不到刚导入的文献

新导入文献需要先完成 OCR 或文本索引。等待处理队列完成后再做全文检索。TXT、Markdown 和 EPUB 通常会更快进入可检索状态。若使用向量检索，还需要完成向量化。

### 扫描件文字错得多

可以在阅读器中进入 **校对模式**，对当前页使用 **重新 OCR 本页**。复杂版面建议尝试视觉 OCR，并使用版式还原校对。

### 导出摘录没有引用

先检查文献元数据是否完整，尤其是题名、作者、年份、来源和文献类型。必要时在文献库中点击 **AI 提取元数据** 或手动编辑元数据。导出时也可切换页码模式（文献页码 / 自然页码）。

### 数据迁移到新电脑

在旧电脑 **设置** 中点击 **导出完整备份**。在新电脑安装软件后，进入 **设置**，点击 **导入备份并恢复**。

## 17. 快速速查

| 目标 | 去哪里 | 使用什么功能 |
| --- | --- | --- |
| 导入 PDF 或图片 | 文献库 / 欢迎页 | 导入文献、拖拽导入 |
| 批量 OCR | 文献库批量菜单 + 处理队列 | 批量 OCR、导入后自动 OCR |
| 修正 OCR / 失败页 | 阅读器校对模式 | 鸟瞰、重新 OCR 本页、视觉 OCR |
| 关键词找资料 | 检索 | 全文检索、筛选、保存检索 |
| 按语义找资料 | 设置向量索引 + 文献库向量化 + 检索 | 向量库检索、文内向量命中 |
| 保存证据 | 检索 / 阅读器 | 保存摘录、批量保存完整段落、导出命中摘录 |
| 写综述 | 研究 | 专题、大纲、带来源综述 |
| 管引用 | 引用格式 | 引用标准、模板、AI 识别 |
| 管主题 | 标签 / 文件夹 / 文献库 | 标签、文件夹、星标、阅读状态 |
| 省空间但保留可补回 | 设置 PDF 原件仓库 | 清理软件内原图、需要时补回（可仅登记路径） |
| 外接 AI 工具 | 设置 → AI 工具连接 | MCP 一键配置 |
| 迁移数据 | 设置 | 导出完整备份、导入备份并恢复 |

完成这些配置后，最常用的日常路径就是：

```text
导入文献 -> OCR -> 元数据整理 ->（可选）向量化 -> 全文/向量检索 -> 阅读校对 -> 摘录 -> 研究专题 -> 引用/导出
```
