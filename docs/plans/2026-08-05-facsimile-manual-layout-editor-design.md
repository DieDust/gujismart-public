# 人工版式编辑器与 Excel 式表格设计

日期：2026-08-05
状态：已确认

## 目标

将现有版式编辑从“顶部按钮加临时输入框”升级为统一、可持久化的人工区块编辑器，并保证人工修改在校对模式、版式还原、文本阅读、全文检索、导入导出和重新打开文献后保持一致。

本次设计覆盖：

- Excel 式表格编辑；
- 文本、标题、注释、摘要、参考文献、页眉、页脚、页码、表格、图片、印章等人工区块；
- 区块新增、移动、缩放、删除、类型切换和阅读顺序；
- 无原图页面与人工空白页；
- 从底图区域生成图片区块；
- 编辑草稿、自动保存、撤销重做和保存失败恢复；
- 阅读、搜索、入库和导出链路兼容。

## 当前问题

1. 表格每个单元格使用独立的 Ant Design 输入框，结构操作全部堆在顶部，选择依赖 Shift 点击，交互不接近常见表格软件。
2. 表格背景写死为白色，但输入文字继承暗色主题的浅色文字，产生白底白字。
3. 进入版式编辑时底图被设置为较高不透明度，同时强制关闭模糊，OCR 文字和底图混在一起。
4. 新建区块会立刻调用页面保存；父组件收到更新后的 OCR 数据后重新初始化编辑器，清空当前编辑索引，因此出现区块闪现后消失、右侧没有输入位置的问题。
5. 新区块没有稳定的人工 ID，编辑状态依赖数组索引，重新排序、保存回传或区块拆分后容易失去选中对象。
6. 当前只能在已有页面上修改已有 OCR 区块，不能创建人工空白页，也没有统一的图片区块创建链路。

## 交互设计

### 画布与底图

- 默认工具为“选择”。单击区块选择，拖动区块移动，拖动八个边缘/角点调整尺寸。
- 空白处拖拽创建区块。鼠标松开后在新区块旁显示类型选择菜单。
- 进入编辑模式时自动开启底图，并使用同一个“底图模糊”设置。
- 首次使用编辑模式时采用推荐模糊度 65；之后沿用用户最后一次手动设置的值。
- 编辑模式不再强制关闭模糊。
- 按住 `Alt` 临时显示清晰底图，松开后恢复用户设置，方便精确对齐。
- 无底图页面显示稳定的纸张背景和边界，所有人工区块操作仍然可用。

### 区块创建与属性面板

- 拖框结束后提供常用类型：正文、注释、表格、图片。
- “更多”菜单包含 OCR 已支持的标题、小标题、摘要、参考文献、页眉、页脚、页码、印章等类型。
- 左侧紧凑工具栏允许预选类型并连续绘制同类区块。
- 右侧使用固定属性面板，不再使用会被父组件刷新关闭的临时悬浮输入框。
- 文本类面板支持文字、横排/竖排、区块类型和阅读顺序。
- 表格类面板打开 Excel 式网格。
- 图片、印章等图像类面板显示裁剪预览、图片说明和重新截取入口。
- 类型可以在保存后切换；切换时保留可兼容的数据，并对可能丢失的结构给出确认提示。

### Excel 式表格

- 单击选择单元格，双击或直接键入进入编辑。
- 鼠标拖动选择矩形区域；Shift 扩展选区。
- 方向键、Tab、Shift+Tab、Enter 在单元格之间移动。
- Delete/Backspace 清空选区；Ctrl+Z/Ctrl+Y 撤销重做。
- 行号和列号用于整行、整列选择；右键菜单提供前后插入、删除、合并和拆分。
- 拖动行列标题边界调整行高和列宽。
- 支持从 Excel、WPS、网页表格复制 TSV/HTML 表格并粘贴到当前单元格。
- 粘贴区域超过现有尺寸时自动扩展行列。
- 保留现有合并单元格数据，并在复制、插入、删除和调整尺寸后规范化合并范围。
- 顶部只保留撤销、重做和必要状态，不再平铺全部结构按钮。

### 空白页

- 在页码区域提供“在当前页前插入空白页”和“在当前页后插入空白页”。
- 新页默认继承相邻页面的宽高、方向和版心；没有相邻页面时使用标准竖向画布。
- 插入操作在数据库事务中完成，统一调整后续物理页码，并刷新文献页数、目录定位、检索快照和阅读进度映射。
- 空白页可以创建任意人工区块；没有底图时图片区块可选择本地图片作为内容。

### 图片区块

- 在有底图的页面上绘制图片区块后，从原始页面图像按规范化坐标裁剪。
- 裁剪结果保存到文献受管资源目录，区块同时保存来源页、裁剪坐标和图片资源路径。
- 阅读和版式还原优先显示独立裁剪资源；资源暂时不可读时可根据来源页和裁剪坐标恢复。
- 图片说明、图题和替代文字进入页面文本与搜索索引；纯图片内容本身不伪造 OCR 文本。
- 在无底图页面上允许通过文件选择或拖放为图片区块提供图片。

## 统一数据模型

人工区块继续存放在页面 `ocr_result.layout_result` 中，避免为不同阅读模式维护第二套版式数据。每个区块至少包含：

```text
manual_block_id       稳定且不可由数组位置推导的 ID
segmentation_source   固定为 manual
label/type/block_type 区块语义类型
location              基于页面坐标系的 left/top/width/height
reading_order         页面阅读顺序
orientation           horizontal 或 vertical
words                 文本类内容或表格的可检索纯文本
rows/cells            表格结构与合并信息（表格区块）
image_asset_path      裁剪图片资源（图像区块）
image_crop            来源页与规范化裁剪坐标（图像区块）
caption/alt_text      图片说明及可检索替代文字（图像区块）
```

旧 OCR 区块在首次人工编辑时补充稳定 ID，不修改未被用户编辑的识别内容。数组索引只用于当前显示顺序，不再作为编辑身份。

## 保存与状态同步

### 编辑草稿

- 页面编辑器维护基于 `pageId + manual_block_id` 的本地草稿。
- 新建区块先进入草稿并立即打开右侧编辑面板，不会在空内容阶段触发父组件重置。
- 属性修改采用短延迟自动保存，同时支持 Ctrl+S 立即保存。
- 页面显示“未保存、保存中、已保存、保存失败”状态。
- 保存失败保留草稿，允许重试；切页或关闭时若仍有未落库草稿则提示用户。

### 防止保存回传清空编辑

- 父组件回传相同页面的新 `ocrResult` 时，编辑器按稳定区块 ID 合并服务端结果与未提交草稿。
- 只有 pageId 真正变化、用户取消草稿或服务端明确接受了对应修订时，才清理编辑状态。
- 每次保存带本地修订号；较旧的异步响应不能覆盖更新的草稿。

### 页面持久化

- 文本类区块生成统一的 `ocr_text` 和 `proofed_text`。
- 表格按阅读顺序生成可检索纯文本，同时保留结构化 rows/cells。
- 图片类只把 caption/alt_text 写入文本流，裁剪资源单独保存。
- 页面保存继续走现有 `updatePage` 主进程边界，并在成功后标记搜索索引过期。
- 新增空白页和裁剪图片使用明确的 IPC，不通过渲染进程直接写文件或数据库。

## 跨模式兼容

- 版式还原：按统一坐标显示全部人工区块；图像区块显示裁剪图。
- 校对文本列表：按 reading_order 显示文本、注释、标题和表格纯文本；图像显示说明。
- 阅读模式：复用统一可读元素解析器，支持表格和图片，不只读取 `ocr_text` 字符串。
- 页内搜索：使用统一页面文本，并通过 manual_block_id/坐标定位命中区块。
- 全文和向量索引：人工保存后使页面索引失效并后台重建；表格文本和图片说明可检索。
- 导入：已有结构化 OCR 数据正常读取；包含人工字段的数据保持兼容。
- 导出：结构化导出保留区块类型、表格结构和图片资源引用；纯文本导出使用统一文本投影。
- 入库状态：人工空白页和人工区块不被错误标记为 OCR 失败；有人工内容的页面属于可读页面。

## 错误处理

- 图片裁剪失败：保留选区和来源坐标，显示重试，不删除区块。
- 原图暂时不可用：保留图片区块元数据，提示重新连接原文或选择替代图片。
- 保存冲突：以较新修订为准，并保留用户草稿副本，禁止静默覆盖。
- 空白页插入失败：整个事务回滚，不留下重复页码或半页数据。
- 表格粘贴异常：无法解析 HTML 时回退 TSV/纯文本；超大粘贴先提示将扩展的行列数。
- 删除含内容区块、行列或合并区域时提供可撤销操作；不可逆资源清理延迟到页面版本稳定后执行。

## 测试范围

- 主题与对比度：暗色/浅色主题下单元格、选区、输入文字和右键菜单可读。
- 新建文本框后右侧面板持续存在，父组件保存回传不会清空编辑。
- 所有人工区块类型在保存、切页、重启后保持类型、坐标、内容和顺序。
- 版式还原、文本列表、阅读模式和页内搜索读取同一份人工结果。
- 全文索引在人工修改后重建并命中新文字、表格内容和图片说明。
- 表格键盘导航、拖选、右键结构操作、合并拆分、整块复制粘贴和自动扩展。
- 底图模糊度首次默认、用户持久化和 Alt 临时清晰显示。
- 空白页前插、后插、事务回滚和后续页码调整。
- 图片裁剪、独立资源读取、原图恢复与无底图图片上传。
- 保存失败、异步响应乱序、页面切换和撤销重做。

## 非目标

- 本次不实现公式计算、跨工作表引用或完整 Excel 文件编辑。
- 本次不对图片内容自动生成新的 OCR；图片说明由用户填写，后续可单独触发区域 OCR。
- 本次不改变已有 OCR 服务商或识别 API 的行为。
