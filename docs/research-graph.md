# 知识图谱工作台

入口：侧栏“知识图谱”。独立页面，可跨研究专题选择当前文献项目内最多 20 个材料集。

## 数据与含义

- 图谱读取已有 AI 研究数据，不自动调用 AI、不发送原文、不重新向量化。“提取关系”只打开已有 AI 抽取流程，有材料时范围为已载入材料涉及的文献，没有材料时为当前文献项目，不自动执行。
- 默认“事件关联”连接事件与同一条记录中的人物、地点、时间。“共现候选”连接同一记录中的所有实体，两者均不自动证明事实。
- “明确关系”读取用户在“字段与关系定义”中指定的主体、关系、客体字段，按字段方向绘制箭头。主客体必须各自只有一个可识别实体，歧义记录不自动展开；材料陈述仍需考证。
- 同类型同名的实体聚合为同名候选组，不等于已完成身份消歧。异名、同名异人、行政区划沿革仍需核验。
- 权重分别显示记录数和文献 ID 去重后的文献数，不是模型置信度或独立史料数量。重复或同源材料需要研究者自行核验。
- 默认排除 `excluded` 记录；“仅已确认记录”只采用 `confirmed` 记录。记录确认不等于自动验证了历史事实。
- 节点及连线保留记录 ID；关联证据展示原文摘录、页码和记录状态，并可跳转阅读器。材料经过修改或被删除时，应重新核验原文。
- 默认识别显式的 person/place/date/event 字段类型和常见字段键名；其他字段可以手动映射。配置及材料集选择按文献项目保存在本地工作区，不改变原始字段定义。
- 人物和地点按分号、顿号、换行拆分。时间和事件保持完整，不自动折算古代纪年，不自动合并异名或同名实体。
- 关系网络、人物考察、地点考察、事件考察、关系考证和时间线索共享材料范围。路径按当前关联类型和已载入材料计算，不区分方向，不是因果链。时间保留原始表述，文本排序不是已完成纪年换算的精确时间轴。
- 证据面板可进行考证修订、添加备注、确认或退回待核验；排除只更新记录状态，不删除原始材料。

## 考察表

- 人物考察列出同条材料人物、涉及地点、原文时间和相关事件；地点考察列出涉及人物、事件及同条材料地名；事件考察列出人物、地点与时间。这些是原始记录内的关联线索，不自动判定交游、到访、迁徙或事件参与事实。
- 关系考证区分主体、客体、关系陈述或线索及方向性质。时间线索保留原始时间表述，缺失信息标为“未记载”，不推定为不存在。
- 各表显示材料条数、按文献 ID 去重的文献数、待核验材料数及出处；表头支持升降序，姓名与时间文本使用中文自然排序。
- 表内即时搜索匹配当前考察对象、关联人物/地点/事件/时间、出处、摘录和考证备注。空格分隔的关键词须同时命中；可筛选含待核验材料或材料全部已确认的对象。
- 表格使用全部已载入材料生成的结果，不受画布 160 节点/500 连线上限影响，但仍受 2,000 条材料读取上限约束。支持每页 12、25、50 项。
- 点击对象或材料数量查看证据；“查看关联网络”定位对应对象。“考证此对象”打开 AI 面板，预填核查问题并限定相关文献范围，不自动发送请求。

## 大库与导出

- 图谱工作台及图引擎按需加载，后台路径算法也单独按需加载。记录在材料集之间轮转读取，每批 100 条，总计最多 2,000 条；超过时显示局部图谱提示。
- 一条记录最多纳入 16 个实体，超过 160 字的实体值不纳入，并显示遗漏数量。
- 当前视图最多显示 160 个实体、500 条连线；按记录数优先展示，定位某个实体后可查看它的一阶邻居。隐藏数量会明确显示。
- JSON 复制当前视图的节点、连线、证据、字段映射、过滤条件和截断信息，适用于可复核的科研交换。CSV 复制当前视图的边表，包含主体、客体、方向、关系标签、记录数、文献数及证据 ID，可导入其他网络分析工具。
- 本功能不增加数据库表、不迁移旧记录、不清理或重建旧向量索引。现有检索、研究结果、摘录和导出入口保持不变。

## 画布操作

- 滚轮以鼠标位置为中心平滑缩放，范围 8%–400%，兼容像素、行和页滚动输入；反向滚动立即改变缩放方向。Shift 加滚轮横向移动。
- 悬停节点或连线查看名称及关联材料数；单击打开证据面板，空白处单击取消选择。双击节点设为中心实体并定位其一阶邻居。
- 右键节点可查看证据、设为中心或路径终点、固定或解除位置固定、复制名称或 ID；右键连线可查看证据、复制名称或 ID。点击外部或 Escape 关闭菜单。
- 拖动节点调整布局；筛选和记录核验时保留已有节点位置及画布视角，窗口大小变化不再自动缩放。主题切换保留位置和选择；暂存位置仅在当前画布会话内有效。
- 工具栏可放大、缩小、恢复 100%、适应画布或显式重新布局；画布获得焦点后可用加减键缩放。

## AI / MCP

新增三个只读工具，均限定在当前文献项目：

- `knowledge_graph_sources`：列出材料集、字段和记录数。
- `knowledge_graph_query`：显式传入 `datasetIds`，可指定关联类型、已确认筛选、最少记录数、中心实体与路径终点。`configs` 与桌面 JSON 导出的配置一致。
- `knowledge_graph_evidence`：按记录 ID 读取状态、摘录和文献页码引用。过长摘录明确标记截断；完整正文继续使用 `get_page_text`。

查询结果含覆盖范围和证据 ID。AI 不应把共现、同名分组或路径解释为事实。三个工具不提供写操作。

## 参考设计

以下仅作为工作流与功能设计参考，未复制源代码：

- [CBDB SQLite](https://github.com/cbdb-project/cbdb_sqlite)：人物、职官信息及随时间变化的地址层级。
- [Palladio](https://github.com/humanitiesplusdesign/palladio)：人文研究中的网络、时间和多维筛选。
- [Gephi](https://github.com/gephi/gephi)：网络探索、过滤、数据交换及可编程分析。

## 验证

```powershell
npm run check:research-graph
npm run build
npm run check:research-graph-ui
npm run check:startup-headless-error
```

逻辑测试覆盖实体类型、旧 JSON 记录、记录状态、证据权重、明确关系、路径、规模上限和滚轮单位归一化。SQLite/MCP 集成测试覆盖项目隔离、轮转分页和证据检索。Electron UI 测试使用独立临时资料库及虚构 IPC 数据，检查画布像素、缩放响应及锚点、悬停、右键、双击、拖动与筛选后的布局保留、视图切换、证据、导出、刷新和宽窄窗口；截图路径在运行结束时输出。测试不访问用户资料库，不发送 AI 请求，不修改系统剪贴板。

启动错误测试需先构建应用，使用临时文件模拟不可用的配置目录，验证 MCP、headless、smoke 三种后台启动受控退出而不阻塞于系统弹窗。`npm run smoke` 会先运行此检查。目录探测并发测试包含在 `npm run check:startup-nonblocking` 中。
