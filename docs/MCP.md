# GujiSmart MCP（AI 工具连接）

让 Cursor、Claude 桌面版、Trae、Codex 等 **本机 AI 工具** 只读访问你的文献库。  
**普通用户不必会敲命令、不必知道盘符。**

## 给电脑小白（推荐）

### 用 Codex 时（你截图里那种表单）

Codex **不能**在无配置时自己发现本机软件（这是安全设计）。但文献管理可以**替你写好配置**：

1. 打开 **文献管理 → 设置 → AI 工具连接**。  
2. 打开 **「允许 AI 工具访问文献库」**。  
3. 点 **「一键写入 Codex 配置（推荐）」**。  
4. **完全退出并重新打开 Codex**。  
5. 直接在对话里问文献库问题。

若你更想手填「连接至自定义 MCP」表单：

1. 类型选 **STDIO**（不要选流式 HTTP）。  
2. 点 **「复制 Codex 表单填写说明」**，按说明粘贴：名称 `gujismart`、启动命令、每一项参数。  
3. 工作目录若说明里有就填，没有可留空。  

### 用 Cursor / Claude / Trae

1. 同样打开开关。  
2. 点 **「复制 JSON（Cursor / Claude / Trae）」**，粘贴到对应 MCP 设置。  

配置会自动带上程序路径、数据目录、连接令牌（**不必自己写 D 盘**）。

> 只有网页版聊天、不支持 MCP 的 AI，无法用此功能。

## 安全

- **只读**：可检索、看元数据、读页文；**不能**删除文献、改设置、读 API Key。  
- 默认关闭；你主动打开开关后才可用。  
- 可随时 **关闭开关** 或 **更换连接令牌**。

## 高级用户（命令行）

仍可用工程内脚本（需 Node 依赖）：

```bash
# 需先在设置中打开「允许 AI 工具访问」，并带上令牌；或开发时设 GUJISMART_MCP_DEV=1
npm run mcp -- --data-dir "<你的数据目录>" --mcp-token "<令牌>"
```

更省事的方式仍是设置里一键复制（已含路径与令牌）。

## 工具一览

| Tool | 作用 |
|------|------|
| `library_search` | 全库检索 |
| `list_documents` | 文献列表 |
| `get_document` | 元数据与页清单 |
| `get_page_text` | 页正文 |
| `resolve_evidence` | 出处解析 |
| `list_folders` / `list_tags` | 文件夹与标签 |
| `library_stats` | 统计 |

## 开发自检

```bash
npm run check:mcp
```
