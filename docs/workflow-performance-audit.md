# 文献处理工作流审查

本轮检查导入、持久队列、OCR 入库、阅读校对、版式编辑、检索和摘录的关键路径。
没有更换数据库结构、OCR 服务商、检索候选算法或旧文献格式。

## 已修复

### 跨页保存

防抖器原先先等待在途保存，再读取待保存快照。如果此时翻页并编辑新页，新页快照
会覆盖前页待保存快照。现在 flush 先固定快照，再排队写入；同页未提交的操作仍可
合并。等待中的失败也会返回 false，而不是被误报为已保存。

原图校对的回调原先丢弃了 onSave 返回的 Promise；现已将实际写入结果交回队列。

### 校对撤销与输入

校对组件收到自身保存回执时，原先重新初始化整个编辑状态，清空撤销历史，并可能
关掉正在输入的另一处编辑。现在用仅存在于渲染器内的标识识别自身回执。
阅读器仅在页号和完整 OCR 载荷都匹配时转交该标识，真正的外部 OCR 更新仍会加载；
翻页后历史重新初始化。标识不会写入用户数据库或导出文件。

### 文本和电子书导入

TXT、Markdown 和 EPUB 原先复制后使用同步 I/O 重读整个文件计算摘要。
现复用 PDF 已有的流式复制与校验，一次读源文件同时写副本和计算 SHA-256，
沿用有节流的进度通知。随后从已复制的文件解析，确保入库内容与文件副本一致。
仍保留完整内容和校验值；没有通过少读文件提升速度。

### 摘录引用

原先对所有摘录直接 Promise.all，同一文献、同一页的重复引用也各调用一次 IPC。
现在每次列表生成内合并相同文献、文献类型和页码的请求，并限制最多 4 个在途调用。
所有摘录仍保留引用，生成失败时每条分别使用自身的历史引用，缓存不跨操作延续，
以免沿用过期的引用样式或文献元数据。

虚构测试：1000 条摘录、20 个不同出处，调用从 1000 次降为 20 次，峰值并发
从 1000 降为 4，输出仍为 1000 条。这是请求数量的测量，不代表全软件快 50 倍。

## 检查边界

- 导入和 OCR 原有的分批事务、事件循环让出、持久任务和重试逻辑继续保留。
- PDF 文本层预检已有基于文件签名的缓存，没有另加未经验证的缓存或扩大并发。
- 原版式草稿的持久恢复、保存确认和放弃补偿路径保留；不是改成仅内存保存。
- 未减少检索文献、正文、校对文本或结果范围，检索完整性由原有回归继续验证。
- 没有调用真实付费 OCR/聊天模型，也没有读写用户真实语料来压测。超大馆藏的峰值内存、
  服务商耗时和 OCR 准确率还需代表性实测，不能据此承诺任意规模都不卡顿。

## 版式校对、页码与检索专项

- 编译后的首开测试复现：首次懒加载校对组件时，Suspense 重放布局 effect，导致文献初始化
  重复执行并把校对模式重置为阅读。初始化现在按打开请求去重，真实的新定位请求仍会加载。
- 版式还原的文字、表格和属性修改现在与几何编辑一样进入页面撤销历史，补齐页面重做。
  连续文字输入按 600ms 间隔分组合并，最多保留 50 个快照；保存回执不清空历史。
- 页面更新明确返回 false 时，不再报告保存成功；跨文献迟到的保存回执不更新另一文献。
- 校准真实页码只写当前页及后续页，不再把之前页面的 OCR/推算来源改为 fallback。
  文献页码用于引用显示，自然页码继续用于原页定位，两者没有混用。
- 校对保存后，当前全文命中延迟合并刷新，不必再次提交同一关键词；不自动发起向量模型请求。
- 索引尚未就绪且没有命中时，原先会一直停在“检索中”。阅读器现在以 1 到 5 秒退避检查
  当前文献索引状态，就绪后重新取命中，失败则显示错误；不反复扫描全文，切换文献后停止旧检查。

`npm run check:facsimile-editing-ui` 使用实际版式组件，测试文字、表格、排版方向、
撤销/重做、失败重试及跨页历史隔离。页码数据库用例纳入 `check:manual-page-insertion`。
`smoke` 新增合成 PDF，验证版式保存后当前检索自动更新，同时保留自然页 1 / 文献页 101。
可用 `node scripts/electron-smoke.js --facsimile-only` 单独运行这一编译后用例。

## 页码与引用联动专项

- 摘录的 `page_num` 是保存时的引用页码。原文可用性原先把它当作自然页码查询，
  现在有定位信息时优先按页面 ID / 自然页码判断，兼容旧 `source_id` 和新定位对象。
- 新生成的引注通过可选的 `sourcePageId` / `sourcePageNum` 查询当前文献页码。
  原有只传 `pageNum` 的调用、手工指定页码范围和字段覆盖继续有效。
- 摘录复制引用与专题 Markdown 导出共用页码来源规则；未指定格式时使用默认引用格式。
  单条复制不再使用界面旧缓存，批量复制也走去重及最多 4 路并发，避免一次触发大量 IPC。
  缓存键包含实际页面来源，防止两页同名页码被错误合并；缓存只活在一次操作内。
- 专题汇总直接读取文献以及引用摘录时，文字中的出处页码也使用校准后的值。
- 返回原文补齐旧 `sourcePageNum` / `internalPageNum` 等字段的读取，不用这些自然页码覆盖引注。
- 不改写旧摘录正文、保存时页码、引用快照或已导出的文件；JSON 专题导出仍是保存记录。
  无法定位的旧记录保留原引用信息，不猜测映射；已有页面 ID 丢失时不回退到另一页。

数据库集成用例覆盖校准后引用、摘录原文可用性、默认格式导出、插页后的稳定页面 ID、
页码范围兼容和历史摘录保持不变。编译烟测串起合成 PDF 校对、检索、摘录、校准、引注和导出。
这些测试不使用真实用户语料或付费 AI/OCR。已打开页面的历史引用显示不做跨窗口自动刷新；
重新生成/复制引用或导出时读取当前映射。
